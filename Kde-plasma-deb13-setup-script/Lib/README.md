# Lib Directory

This directory is intended for shared library files, utility scripts, and common functions that can be used across the setup scripts in this repository.

## Purpose

The `Lib` folder serves as a central location for:
- Reusable bash functions
- Common utility scripts
- Shared configuration helpers
- Library files that support the main setup scripts

## Usage

Scripts in the main directories (`Automated Setup`, `Startup`) can source files from this directory to avoid code duplication and maintain consistency.
